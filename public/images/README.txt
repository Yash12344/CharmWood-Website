              CHARMWOOD WEBSITE — HOW TO REPLACE PHOTOS
====================================================================

Everything the website shows in a photo lives in this folder.
To change any picture on the website, you just:

    1. Save your new photo with the EXACT SAME NAME as the old one
    2. Drop it into the correct folder (replacing the old file)
    3. Save. Refresh the site. Done.

You do NOT need to touch any code.

IMPORTANT RULES
--------------------------------------------------------------------

* The file NAME must match exactly — including capital letters and
  the ".jpg" at the end. For example:
      Yes: slide-1.jpg
      No:  Slide-1.jpg
      No:  slide 1.jpg
      No:  slide-1.JPG

* You can only replace .jpg files with other .jpg files.
  If you have a .png or .jpeg photo, rename it to end in .jpg
  or ask the developer to switch it for you.

* Recommended photo sizes (larger is fine, will be scaled down):
      Hero slides & main About      1600 x 1200 px  or bigger
      Campus Life gallery           1000 x 1000 px  or bigger
      Small polaroids               600 x 800 px    or bigger
      Parent photos                 400 x 400 px    or bigger
      Family circle avatars         200 x 200 px    or bigger

* For best results, use landscape (wide) photos for the hero and
  About sections, square photos for the parent avatars.

* Photos with people looking at the camera and smiling do best.
  Natural sunlight beats indoor fluorescent light.

--------------------------------------------------------------------
IF A PHOTO IS MISSING
--------------------------------------------------------------------

If you haven't added a photo yet, the website will automatically
show a temporary stock photo in its place so nothing looks broken.
The moment you drop the real file in, the temporary photo is gone.

--------------------------------------------------------------------
TROUBLE?
--------------------------------------------------------------------

If a new photo isn't showing up after refresh:
    1. Check the file name is EXACTLY right (see rules above)
    2. Check the file is in the correct folder
    3. Do a hard-refresh in your browser:
          Windows/Linux:  Ctrl + F5
          Mac:            Cmd + Shift + R

If it still doesn't work, contact your developer.
